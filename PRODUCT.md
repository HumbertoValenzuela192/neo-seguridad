# Producto

Web comercial pública de Tigrr Security y presentación de NEO. Explica las dos soluciones: central de monitoreo 24/7 y plataforma para una central propia. Su acción principal es solicitar una evaluación.

El alcance de este repositorio es contenido comercial, navegación pública y formulario de contacto. La operación interna tiene un repositorio y despliegue independientes; no forma parte del código ni del build público.

Prioridades: claridad comercial, formulario con entrega verificable, uso móvil y conservación de la marca existente. No añadir cifras, testimonios ni capacidades inventadas.
