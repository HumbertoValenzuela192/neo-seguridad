# Neo Monitoring — Sitio demo

Proyecto simple de landing para una empresa que vende un sistema de monitoreo.

Instrucciones rápidas:

1. Mantén la imagen `a2791a37-6fe2-413d-9f5a-526532134dcc.jpg` junto a `index.html`.
2. Abre `index.html` en tu navegador.

Notas:
- `index.html` carga la imagen directamente desde la raíz del proyecto.
- El formulario de contacto es de ejemplo y muestra una alerta en envío.
